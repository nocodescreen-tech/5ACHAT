# 5ACHAT — Design system V1

Reference: UI/UX Pro Max public skill (nextlevelbuilder/ui-ux-pro-max-skill). Rules adapted manually; CLI not run in this environment.
- Product: procurement / personal and small-business financial utility.
- Visual: 5DEV identity: warm white, charcoal black, orange #F97316; dark orange #C24B09 for accessible white-button text; no decorative gradients or random emoji icons.
- Typography: system sans, 16px base, compact numeric hierarchy, tabular amounts.
- Navigation: five labeled destinations, bottom on mobile with safe-area spacing.
- Touch: target 44px minimum; native checkboxes with an enlarged label hit area; visible focus, keyboard support, contrast.
- Motion: 180ms fade/translate for changing screens, reduced-motion respected.
- Finance: currency always visible; no implicit conversion; unknown price distinct from zero.
- Data: clearly distinguish local, synced, conflict, offline and failed. Never imply cloud sync before acknowledgement.
- Forms: label inputs, inline feedback, confirmation before replacing data.
- QA required: 360px mobile, 768px tablet, desktop; Android keyboard, screen reader, reduced motion, offline/reload and cloud conflict. Not yet verified on device.

- Logo: custom 5/check monogram, charcoal background, white numeral and orange check. Dark theme and high-contrast action states.
